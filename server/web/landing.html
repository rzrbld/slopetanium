For PortMaster · free and open source

Your handheld's ports, always up to date

Slopetanium watches the GitHub releases of the PortMaster ports you play. It updates them, rolls them back and backs them up, from a console-style menu on the handheld or from any browser on your Wi-Fi.

Everything a port needs, after it's installed

PortMaster installs a port once. Slopetanium looks after it from then on, using PortMaster's own installer, so every firmware PortMaster supports is handled its way.

New releases, noticed

Watch any GitHub repo that publishes a PortMaster zip. Slopetanium checks on start and every few hours, and marks the ports with an update.

Update, roll back, any version

Install the newest release or an older one. The last versions you installed stay on the handheld, so a rollback works offline.

Skip a broken release

Mark a release as unstable and roll back. It isn't offered again; the next release is.

Safe installs

Free space is checked before downloading and unpacking, and low battery without the charger asks first. Saves are backed up before every update.

Game files from your PC

Drop files or whole folders in the browser. Uploads resume after a Wi-Fi drop, and 4 to 9 GB images are fine on exFAT cards.

Your GOG library

Sign in to GOG.com once. Ports of games you own there get their installer downloaded straight into the port.

File browser and config editor

Put saves in place, install mods, download any file or folder, and edit configs in the browser, keeping their encoding and line endings.

Move a game to another handheld

Download the whole game with its imported data as one zip, and restore it on the other handheld. It starts without importing again.

Clean up after imports

Installers and CD images take gigabytes once a port has imported them. See which ones and free the space.

On the handheld

A shelf of box art you browse with the D-pad, at 60 frames per second. It's built on the BananaOS launcher engine, with Slopetanium's own look.

  • One screen or two. On a dual-screen handheld such as the RG DS, the top screen shows the selected port; the bottom one holds the shelf, and you can tap it.
  • A to open, Start to update all. Each port's menu has update, roll back, other versions, backups and its game files.
  • Connect shows a QR code and a PIN for the web page.

From any browser

Open Connect on the handheld, scan the QR code, and manage everything from your PC, tablet or phone on the same Wi-Fi.

  • Library with covers, versions and one-click updates.
  • Files for each port: upload, download, rename, edit.
  • Backups of saves or the whole game, restored with a drop.
  • PIN-protected, and only on your local network.

Shared by the community

Share the ports you watch and find the ones others share, with ratings and reviews written on handhelds. Add one in Slopetanium's Community page and it comes with the settings its sharer used.

Get started

Slopetanium is a PortMaster port itself. It runs wherever PortMaster runs and needs nothing else.

Download

slopetanium.zip from the GitHub releases.

Install

Put the zip in PortMaster/autoinstall and open PortMaster, or unpack it into your ports folder.

Open it

Start Slopetanium from Ports. Add repos in the web page via Connect, or pick ports from the catalogue and the community.

Open source

MIT licensed, on GitHub. The menu engine comes from BananaLinux, also MIT.

No account

The community knows a handheld only by a hashed random id. Install counts are opt-in and never include where you are. Details.

Your files stay yours

Updates unpack over the port like PortMaster does, so saves, settings and imported game data are kept.

Keep playing, Slopetanium keeps up

Free, for every handheld PortMaster runs on.
