How the community works

Slopetanium installs and updates PortMaster ports that are published as GitHub releases. On a handheld, a port you watch can be shared with the community: it then appears here, so others find it, install it from Slopetanium and keep it updated.

Reviews and ratings

Reviews are written in Slopetanium, on a handheld; this website only shows them. Each handheld has one review per port, and can change or delete it.

Installs

A handheld counts its installs only if its owner said yes when Slopetanium asked (it can be switched off in Settings). Then each installed version of a port shared here counts once per handheld, with the handheld's model and firmware, including ports installed before. Sharing a port also counts the sharer's own install, without model or firmware unless they said yes. Nothing about where you are is recorded.

What is stored

  • No accounts, no names, no addresses. Slopetanium makes a random secret on each handheld. This server keeps only a keyed hash of it, which ties a handheld's reviews and shares together but can't be turned back into the secret.
  • A display name, if you set one in Slopetanium; otherwise a made-up one, such as “Mint Otter 3f2a”.
  • Your reviews, the ports you share, and install counts as described above.
  • No IP addresses or locations are written down. They are used only in memory, to limit how fast one network can post.

Taking things down

Unshare a port in Slopetanium and it leaves the list once nobody else shares it. Reviews that are abuse or spam are removed. To report something, open an issue on GitHub.

For developers

The data is public and read-only at /v1/ports and /v1/ports/owner/name (JSON).
